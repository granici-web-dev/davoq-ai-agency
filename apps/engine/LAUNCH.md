## 1. Сервер и развёртывание

Да, сервер нужен, и один. Виджет — это `<script src="https://…">` на чужой
странице: с localhost его не подключить, а по HTTP браузер заблокирует запрос
с сайта на HTTPS.

Что на нём крутится: API, воркер очереди, Postgres с pgvector, Redis, папка
с материалами клиента и обратный прокси с сертификатом. Без serverless: нужен
Postgres с векторным поиском, живые SSE-соединения и очередь — всё это состояние.

Пилоту хватит машины на 2 ядра и 4 ГБ (Hetzner CX22, ≈4 € в месяц) с большим
запасом. Место занимают материалы и переписки, а не вычисления: считает Bedrock.

- [ ] **[вы]** Арендовать сервер и завести домен для API (например `bot.assistwidget.ro`).
      Нужен доступ по SSH и возможность прописать A-запись.
- [ ] **[я]** `Dockerfile` и `docker-compose.prod.yml`: API, воркер, база, Redis, прокси.
      Сейчас `docker-compose.yml` — только для разработки, в нём нет ни приложения,
      ни сертификатов.
- [ ] **[я]** Команда запуска из собранного кода. Сейчас её нет вовсе: `npm run dev`
      это `tsx watch`, для боевого сервера он не годится.
- [ ] **[я]** Caddy для TLS — сертификат он берёт и продлевает сам.
- [ ] **[я]** Резервные копии базы: ежедневный дамп и **проверенное восстановление**.
      Копия, которую ни разу не разворачивали, — это не копия. В базе лежат все
      материалы, переписки и заявки.
- [ ] **[вместе]** `SECRETS_KEY` в окружении сервера.
      **Менять его нельзя никогда** — со сменой ключа токен Google Drive и ключи
      коннекторов станут нечитаемыми, и восстановить их будет неоткуда.

  длительный — нет.

  клиента ещё не было.
