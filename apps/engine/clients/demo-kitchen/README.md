# Demo Kitchen

Ниша: **Кастомная мягкая мебель** (`furniture`) · сайт: demo-kitchen.example · язык: ro

## Что сделать

1. Заполнить `config.yaml` — всё, где стоит TODO.
2. Сложить материалы в `knowledge/` по разделам.
3. Применить: `npm run client apply demo-kitchen`
4. Завести пользователя панели: `npm run cli create-user <tenantId> <email> <пароль>`
5. Отдать клиенту сниппет из раздела «Instalare».

## Что запросить у клиента

- [ ] Каталог: модели, размеры, из чего состоят
- [ ] Цены: где опубликованы, что считает менеджер, что фиксировано
- [ ] Ткани и наполнители: названия, категории, чем отличаются
- [ ] Сроки изготовления и доставки по городам
- [ ] Гарантия, возврат, обмен
- [ ] Шоурумы: адреса, часы работы, как добраться
- [ ] Рассрочка и способы оплаты
- [ ] FAQ: вопросы, которые чаще всего задают продавцам
- [ ] Примеры переписок или звонков, если сохранились

## Что здесь НЕ хранится

Секреты. Токен Google Drive и ключи коннекторов шифруются `SECRETS_KEY`
и лежат в базе — клиент подключает их сам из панели.
